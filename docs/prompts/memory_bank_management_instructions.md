# Memory Bank Management Instructions

Инструкции по управлению и обновлению Memory Bank проекта gelyrix.com.

**Последняя редакция:** 2026-05-31 12:52:45

## Обзор

Memory Bank содержит критически важную информацию о проекте:

- **activeContext.md** — текущий статус, недавние изменения, открытые вопросы
- **productContext.md** — описание продукта, архитектуры и технического стека
- **systemPatterns.md** — архитектурные паттерны и соглашения кодирования
- **decisionLog.md** — логирование архитектурных и реализационных решений
- **progress.md** — отслеживание прогресса и список задач
- **system_full_info_x200.md** — информация о среде выполнения и системе

## Правила обновления

1. **Все записи должны быть на русском языке** (кроме кода, имён файлов, API)
2. **Формат даты:** ГГГГ-ММ-ДД ЧЧ:ММ:СС (UTC)
3. **Сортировка:** новые записи добавляются в начало раздела (обратный хронологический порядок)
4. **Формат записи:** `[дата] - [описание]`

## Когда обновлять Memory Bank

### activeContext.md
- Когда меняется текущий фокус проекта
- При возникновении открытых вопросов или проблем
- При значительных изменениях в среде выполнения
- После завершения важных задач

### productContext.md
- При изменении целей проекта
- При добавлении новых переменных окружения
- При изменении архитектуры или стека технологий
- При добавлении новых маршрутов или функциональности

### systemPatterns.md
- При введении новых архитектурных паттернов
- При изменении соглашений кодирования
- При обновлении зависимостей (мажорные версии)
- При изменении структуры проекта

### decisionLog.md
- При принятии важного архитектурного решения
- При выборе альтернативного подхода
- При обосновании технических выборов

### progress.md
- Каждый день разработки или при важных вехах
- При завершении задачи
- При переходе к новой фазе проекта

## Процесс обновления

1. Откройте соответствующий файл Memory Bank
2. Добавьте новую запись в начало нужного раздела
3. Используйте текущую UTC-дату и время
4. Напишите краткое, но информативное описание
5. Сохраните файл
6. Обновите file hashes: `find memory-bank -name "*.md" -type f -exec sha256sum {} \; | sort -k2 > memory-bank-analysis-hashes.txt`

## Пример обновления progress.md

```markdown
## Текущие задачи

2026-05-31 13:00:00 - Завершена интеграция Appwrite CMS в админ-панель
2026-05-31 12:52:45 - Проект находится в активной разработке...
```

## Проверка целостности Memory Bank

Выполните команду для вычисления текущих хешей:

```bash
find memory-bank -name "*.md" -type f -exec sha256sum {} \; | sort -k2 > memory-bank-analysis-hashes.txt
```

Сравните с последней сохранённой версией:

```bash
diff memory-bank-analysis-hashes.txt memory-bank-analysis-hashes.txt.backup
```

## Бэкап Memory Bank

Перед значительными изменениями создайте бэкап:

```bash
cp -r memory-bank/ backups/memory-bank-$(date +%Y-%m-%d_%H-%M-%S)/
```

## Интеграция с CI/CD

При необходимости добавить автоматическую проверку целостности Memory Bank в CI/CD pipeline (GitHub Actions, GitLab CI и т.д.).
