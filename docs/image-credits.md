# Image credits

This document records the visual assets currently used by the public draft of Gelyrix.

## Current status

The current image set already follows the selection rules for the partner-safe draft:
- no faces in hero or lab imagery;
- no doctor/patient imagery;
- no sci-fi capsule visuals with a person;
- emphasis on laboratory equipment, cryogenic vessels, and research environments.
