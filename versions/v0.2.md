# Gelyrix site implementation v0.2

Key deltas from v0.1:

- Added a working SvelteKit site structure for the requested sitemap.
- Expanded RU/EN content for home, about, how-it-works, services, lab, transparency, blog, FAQ, investors, contacts, and legal pages.
- Added launch blog article stubs with real slugs and localized article pages.
- Added two contact flows: consultation request and research/investment participation.
- Added SEO titles, descriptions, OpenGraph images, breadcrumbs, and future monitoring/dashboard placeholders.
- Kept the site static-friendly while leaving room for Appwrite-backed forms, blog editing, monitoring APIs, and a future client/investor cabinet.

Implementation notes:

- Shared content is stored in `src/lib/content.ts`.
- Reusable hero and breadcrumb UI lives in `src/lib/components/`.
- External editorial images are referenced from Unsplash URLs and can be replaced with licensed brand assets later.
- Cryonics and neurosafekeeping are consistently described as experimental methods without revival guarantees.
