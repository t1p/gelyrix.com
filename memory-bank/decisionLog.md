## Решение: Выбор SvelteKit в качестве фреймворка

2026-05-31 12:52:45 - Memory Bank инициализирован.

### Обоснование

SvelteKit выбран для обеспечения полнофункционального фреймворка с встроенной поддержкой SSR, статического экспорта и development experience. Позволяет использовать TailwindCSS для стилизации без излишней сложности и обеспечивает хорошую производительность.

### Детали реализации

SvelteKit 2.49.1 используется с Node adapter для развёртывания на сервере. Все маршруты находятся в src/routes/. Server-side логика реализуется через +page.server.ts и hooks.server.ts.

## Решение: Использование Appwrite для Backend

2026-05-31 12:52:45 - Memory Bank инициализирован.

### Обоснование

Appwrite BaaS (Backend-as-a-Service) предоставляет готовое решение для аутентификации, базы данных и хранилища файлов. Снижает необходимость в разработке собственного backend-а и упрощает развёртывание. Поддерживает REST и SDK для JS/Node.js.

### Детали реализации

Client SDK (appwrite 21.5.0) для браузера, Server SDK (node-appwrite 24.0.0) для backend операций. Database: gelyrix_cms, Collection: cms_documents. Endpoints и credentials хранятся в переменных окружения.

## Решение: Трёхязычная локализация (EN, RU, ES)

2026-05-31 12:52:45 - Memory Bank инициализирован.

### Обоснование

Проект требует поддержки русского (основной язык), английского (международный) и испанского (расширение аудитории). svelte-i18n обеспечивает удобный API для переводов и автоматическое определение локали браузера.

### Детали реализации

JSON файлы переводов: src/lib/translations/{en,ru,es}.json. Инициализация в src/lib/i18n.ts. Функция pick() для выбора контента по локали. Сохранение выбранной локали в localStorage.

## Решение: Node Adapter и PM2 для Deployment

2026-05-31 12:52:45 - Memory Bank инициализирован.

### Обоснование

Node adapter позволяет развёртывать SvelteKit как Node.js приложение на dedicated сервере. PM2 обеспечивает управление процессом, автоматический перезапуск и мониторинг. nginx служит обратным прокси для обработки HTTPS и балансировки нагрузки.

### Детали реализации

ecosystem.config.js содержит PM2 конфигурацию. nginx/gelyrix.com.conf конфигурирует reverse proxy. npm run start запускает production build через Node.

## Решение: Versioning контента через версионные файлы

2026-05-31 12:52:45 - Memory Bank инициализирован.

### Обоснование

Версионные файлы (versions/v0.1.md, versions/v0.2.md) позволяют отслеживать эволюцию контента и архитектуры проекта без изменения производственного кода. Предыдущие версии сохраняются для истории.

### Детали реализации

versions/v0.1.md сохраняется неизменным как baseline. Каждая новая версия создаётся как versions/vX.Y.md и начинается с описания ключевых изменений.
